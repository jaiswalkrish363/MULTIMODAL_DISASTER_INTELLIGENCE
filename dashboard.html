ℹ About This Project

The Multimodal Disaster Intelligence Platform analyzes historical disaster-related information and estimates district-level risk categories using machine learning.

The current numerical prediction system uses a trained Random Forest classification model.

The platform includes historical data analytics, machine learning-based risk prediction, image upload functionality and an interactive geographical map.
